# Rename the successor extension to pi-charter

Status: accepted

We are building `pi-charter`, not `pi-goals v2` and not `pi-missions`. `pi-missions` is already a live Pi extension with severe design overlap, and `pi-quests` is also taken; `pi-charter` is verified clean in the Pi/agent space and better names the binding document that authorizes and constrains the run. The old v1 goals code is retained only as reference material.
